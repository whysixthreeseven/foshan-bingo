Генерирует изображение для игры в бинго (формат 3 на 3). Для генерации используется рандомно выбранные варианты из общего списка и (ограниченное) некоторое количество вариантов из перманентного списка.

Можно настраивать размер карточек (рекомендуется 300 на 300 пикселей), а также выбирать случайный цвет для заднего фона. Скрипт не подбирает допустимую длину текста для каждой карточки и не разбивает на слова для перевода на новую строку. Все варианты изменены и в них вручную добавлены "новые строки".
